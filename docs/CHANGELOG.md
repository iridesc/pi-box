# 能力变更日志

给 agent 读。记录**能力层面**的变化，不是 commit 流水账。

用途：当有人问「pi-box 支持 X 吗」，先查这里，再查源码。这里的条目可能比你的记忆新。

格式：倒序。每条只说「多了什么能力 / 修了什么坑」，不写实现细节——细节去源码。

---

## 2026-11

### 界面

- **项目设置改成弹窗**。原来占满第三栏，现在弹窗内完成改名 / 删除 / 子 Agent 管理 / 定时任务。第三栏不再被占用。
- **子 Agent 管理收进项目设置**。左栏不再有「子 Agent」标签和 ＋ 按钮，只留一条分割线。
- **报告入口改为左栏节点**。左栏「📊 报告」→ 第二栏组列表 → 第三栏详情，和「助理 / 文件」同构。不再是四级树。
- **弹窗尺寸全部放大一档**。基础 640、助理设置 820、项目设置 880、报告组 660、图标选择器 470，最大高度 92vh。

### 图标

- **项目 / 助理 / 子 Agent 的图标可以自定义**（emoji）。
  - 项目图标存 `<项目>/.pi/project.json`，助理和 Agent 图标存各自 `.md` 的 frontmatter `icon` 字段。
  - 内置 66 个 emoji 可选；未设置时用默认值（项目 📁、助理 🤖、子 Agent 🤖）。
  - 元项目图标锁定不可改。
  - 文件树里的文件图标固定，不参与自定义。

### 报告

- **报告组（Report Group）**。agent 通过 `report_publish` / `report_list` / `report_read` / `report_delete` 四个工具发布报告。
  - 报告落在 `<项目>/.pi/reports/<组名>/`，每次发布是一个独立完整的文档（时间戳命名），**没有版本链**。
  - 前端有全屏阅读页，支持 ←→ 切换、Esc 关闭、预取相邻。
  - HTML 报告必须单文件自包含，外链脚本/样式/图片一律拒绝。
  - **公开链接**：组可以设为公开，得到 `/r/<slug>` 稳定 URL，可分享给外部。
  - 公开后新发布的报告自动公开。
  - **可见性只能由人在界面上操作**，agent 没有设置可见性的工具。
  - agent 必须在其 frontmatter 里绑定 `reports: [组名]` 才能发布到该组。
  - 报告内容在 iframe sandbox 中渲染，CSP 关闭一切网络请求。

### 文件

- **项目文件浏览**。可以列目录、预览文本与代码（带高亮）、下载原文件、上传。
  - 只允许访问项目根目录内部，挡掉了 `..` 和符号链接越界。
  - 「文件」入口图标是 🗄️。

### 性能

- **SSE 增量渲染**。长会话不再整段重绘，单次处理从约 367ms 降到约 8ms。
- **静态资源 gzip + ETag**。首屏要下载的资源从约 339KB 降下来，支持 304 协商。
- **首屏快照瘦身**。`/api/state` 响应体积下降约 90%，首屏从约 9.6s 降到约 4.5s。

### 定时任务

- **支持三种执行方式**：纯命令、纯 LLM、命令 + LLM。
  - 纯命令任务没有 LLM，**没法写报告**。要写报告就用「命令 + LLM」：命令把结果写文件，LLM 段读文件再总结。
  - 命令的 stdout 只保留尾部 16000 字符，提示词模板只用其中 4000，数据量大必须走文件。
- **修复 cron 任务永不自动触发**的问题。
- `{{stdout}}` 只取 stdout，stderr 单独进日志。

### 其他

- 系统设置里可以自定义页面标题和标签页图标。
- 内置 msg-hub 消息渠道 MCP（构建期拉取）。

## 维护约定

- 每次发版在这里加一条，写「能力」，不写「文件改了哪几行」。
- 如果某项能力被移除或行为变了，在对应条目下写「已变更：」，不要直接删掉旧条目。
- **不写任何部署信息、主机地址、账号、密钥、内部域名。** 这份文件会进镜像，agent 能读到。
